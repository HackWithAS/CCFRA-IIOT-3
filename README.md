# Credit Card Fraud Risk Analysis

A Power BI and Data Analytics project focused on identifying fraud patterns in credit card transactions through interactive dashboards and visual analytics.

## Project Overview

This project analyzes historical credit card transaction data to identify suspicious patterns, fraud-prone categories, high-risk locations, and transaction trends. The dashboard helps visualize fraud metrics and supports decision-making for fraud monitoring.

## Features

* Fraud Rate KPI Tracking
* Fraud Type vs Transaction Category Analysis
* Risk Level Distribution Visualization
* State-wise Fraud Detection Analysis
* Monthly Fraud Trend Monitoring
* Interactive Filters / Slicers

## Tech Stack

* Power BI
* Power Query
* DAX
* Microsoft Excel / CSV
* Python (Autoencoder Notebook)

## Files Included

* `report.pdf` – Detailed Project Report
* `dashboard.pbix` – Power BI Dashboard File
* `fraud-detection-autoencoder.ipynb` – ML Fraud Detection Notebook
* `screenshots/` – Dashboard Images

## Key Insights

* Fraud Rate Observed: 28.60%
* Top Fraud Type: Card Not Present
* Highest Fraud States: Maharashtra, Karnataka, Rajasthan
* Fraud Peaks During: July, August, December
